# Shatterbox

Собственный воксельный движок для тактического арена-шутера с полной разрушаемостью укрытий.

- Стек: Rust 2024 + wgpu 30, winit 0.30, egui 0.37, Jolt Physics 5.6 (oxijolt), Lua — позже.
- Рендер: deferred без треугольников, DDA по brick map, DDGI, мягкие тени, TAAU/FSR.
- Платформы: Windows (DX12, fallback Vulkan) + Linux (Vulkan); консоли не планируются.
- Цель: RTX 3050 8GB, 1440p output, 144 fps в типовых сценах (internal 720–900p + апскейл); 100–120 в тяжёлом разрушении, 60 — нижняя граница.
- Масштаб: фиксированная арена 256×256 м (высота 64 м), режим 5×5 с ботами. Открытый мир и streaming — вне текущего скоупа.

## Статус

Фаза 0 (каркас и performance harness) закрыта:

- Cargo workspace: `shatterbox-core`, `shatterbox-platform`, `shatterbox-gpu`, `shatterbox-voxel`, `shatterbox-physics`, `shatterbox-destruction`, `shatterbox-render`, `shatterbox-game`.
- Окно winit, wgpu с DX12 → Vulkan fallback на Windows и Vulkan на Linux.
- Free-cam, ввод, egui-оверлей, GPU timestamps, frame governor, internal render target с апскейлом.
- Hot reload шейдеров, CI-конфиг Windows + Linux, headless GPU smoke-тест.

Фаза 1 (воксели и DDA) закрыта:

- `shatterbox-voxel`: палитра, воксель `u16`, кирпичи 16³, регионы 32 м, арена 8×2×8 регионов, CPU-референс DDA, детерминированный хеш.
- Тестовая арена: пол 64×64→192×1×192 м, стены, колонны, ящики, арка, башня, песок, опасные барьеры, эмиссивные вставки.
- GPU compute DDA: регион 32 м → группа 8 м → кирпич 2 м → маски 1/0.5/0.25 м → mask16, без делений в горячем цикле.
- Оверлей: FPS, CPU/GPU/pass timings, internal/output resolution, render scale, состояние governor, hot reload, статистика мира, CPU-луч.

Фаза 2 (базовый рендер) закрыта:

- Кадровый граф: `gbuffer.wgsl` (иерархический DDA + воксельный AO + один теневой луч) → `lighting.wgsl` (deferred PBR: sun, небо с процедурными облаками, до 8 point lights, fog) → `temporal.wgsl` (TAAU с Halton-джиттером и depth-reprojection) → `bloom.wgsl` (1/4) → `post.wgsl` (ACES, grade, vignette) → egui.
- Мягкие тени без доп. лучей: направление солнца наклоняется внутри солнечного диска по blue-noise пикселя и номеру кадра, двоичная проверка даёт дизеренную полутень; TAA накапливает её в гладкий градиент. Хеш мировой позиции для этого не годится — даёт периодические волны вблизи и крапинку вдали.
- Вид: солнце под ~50°, контрастный ambient sky/ground, дешёвый back-lit bounce, 4-метровые швы плит и кладка на материалах, фаска вокселя, макро-вариация 1–3 м, облачная пелена в небе.
- Frame governor: EMA игнорирует кадры дольше `target * 2.5`, тик 0.5 с, шаг ±0.05 при 1.45/1.05 от бюджета — разрешение поднимается обратно, а не залипает на минимуме.
- Замеры (RTX 3050, DX12, release, 2560×1440 output, NO_VSYNC): internal 1600×900 — **157.9 fps** (p50 159.4, GPU 6.52 мс); internal 1280×720 — **216.8 fps** (p50 220.6, GPU 4.60 мс). Разбор G-буфера на 900p: DDA ≈2.9 мс, теневой луч ≈1.4 мс, стилизация ≈1.4 мс при полном кадре 5.7 мс.

Фаза 3 (разрушение и физика) — вертикальный срез готов:

- `shatterbox-voxel::edit`: детерминированные команды `VoxelCommand::{remove,add}`, сферическая кисть 6–14 вокселей с rim-джиттером, dirty-кирпичи без дублей; `VoxelWorld::take_voxel`.
- `shatterbox-physics`: трейт `PhysicsBackend` + Jolt 5.6 через oxijolt, compound box-коллайдеры, масса/трение/демпфирование, сон тел (`allow_sleeping`), `MotionQuality::LinearCast`. Игра не видит Jolt API, есть fallback-точка для Rapier.
- `shatterbox-destruction`: закон сохранения — все выбитые воксели уходят в 2–6 обломков (сумма `voxel_count` равна числу удалённых), плотная локальная сетка, масса/центр масс/тензор инерции считаются по вокселям и плотности палитры, а скорость и вращение — из энергии выстрела и геометрии взрыва (никаких заранее заданных м/с и рад/с); compound-коллайдер совпадает с визуальным куском, так что обломки реально сталкиваются с полом, стенами и друг с другом; ПКМ-заливка возвращает материал. Обломки живут на карте бессрочно и засыпают.
- Рендер обломков: до 64 инстансов / 524 288 вокселей, AABB → локальный DDA по оригинальным вокселям, работают AO, материалы и микро-джиттер.
- Инкрементальный GPU-upload: `WorldMirror` на 16 384 кирпича, обновляются только dirty-кирпичи и occupancy-текстуры.
- Арена: кладка с утопленными швами, цоколи/карнизы/пилястры/колонны, окна с нишами, рамами и подоконниками, ящики с рёбрами и ручками, контейнеры, рустованная арка с emissive-табло, лестница, башня, барьеры, лампы; плиточные швы, бордюры, канавка, тактильная полоса.
- Фотореализм: микро-джиттер ±4 %, влажный бетон roughness 0.25, тёмный металл metalness 0.9, контактный AO, мягкая полутень, GGX, bloom, дымка, ACES.
- Управление: ЛКМ — выстрел (сфера 10 вокселей, screen shake 60 мс), ПКМ — заливка, СКМ — обзор. Физика 60 Гц, рендер интерполируется.
- Исправлен баг масок занятости: удаление одного вокселя больше не обнуляет весь coarse-блок 2³/4³/8³; маски пересчитываются из детей. Это убрало проваливание лучей под пол и шум теней.
- Тесты: voxel 27, destruction 3 (сохранение, заливка, детерминизм), physics 1 (падение/сон), render 4; workspace зелёный. Замер: 900p internal при 1440p output — **149.1 fps mean / p50 150.4**, GPU 6.55 мс.

## Запуск

Из корня репозитория:

```powershell
cd E:\vox_engine
cargo run -p shatterbox-game
```

Release-сборка (для замеров и нормального FPS):

```powershell
cargo run -p shatterbox-game --release
```

Готовый бинарник после сборки:

```powershell
.\target\release\shatterbox.exe
```

Первый запуск компилирует workspace; дальше старт занимает секунды. Окно 1600×900, vsync включён.

## Управление

- Мышь — обзор без зажатия кнопок: курсор захватывается при старте/фокусе, Esc отпускает, клик по окну захватывает снова.
- ЛКМ — выстрел по направлению камеры: сфера повреждения 10 вокселей, выбитый материал отваливается динамическими обломками Jolt (заряд 0.15 кг в тротиловом эквиваленте ≈ 627 кДж; скорость и вращение каждого куска считаются из импульса, массы и тензора инерции, без заранее заданных констант); при остановке тела засыпают.
- ПКМ — заливка: возвращает воксели бетона сферой в пробоину, обломки при этом остаются на карте.
- WASD — ходьба, Space — прыжок, Shift — бег.
- `[` / `]` — время суток назад/вперёд (0.5 ч, с Shift — 2 ч); основной способ — слайдер в оверлее.
- Колесо — чувствительность мыши, R — респавн на полу.
- F1 — оверлей, F2 — включить/выключить frame governor, F3 — фиксированный render scale.
- В оверлее (F1) блок Environment: слайдеры времени суток (0–24 ч) и температуры солнца (2000–12000 K); блок Effects: чекбоксы Voxel RT shadows, SSAO, SSGI, Voxel cone tracing, TAA, Volumetric fog и кнопки All on / All off. Переключение применяется со следующего кадра, пайплайны не пересобираются.
- F11 — полноэкранный режим (borderless).
- Esc — освободить курсор.

Прицел — крестик в центре экрана. Выстрел и рендер используют одну и ту же камеру, а mouse look применяется до трассировки луча. Центр сферы разрушения — ровно первый твёрдый воксель под лучом: раньше к нему прибавлялся `abs(normal)`, из-за чего воронка на гранях −X/−Y/−Z уезжала в сторону и «стреляла за объект». Отдача убрана: раньше она двигала камеру и давала рассинхрон с лучом.

На арене есть закрытый неоновый комплекс (x 72–94 м, z 100–125 м): коридор и две комнаты с синими, малиновыми, зелёными и белыми emissive-трубами и цветными лампами. Всё разрушается.

## Производительность

- `SHATTERBOX_QUALITY=performance|balanced|quality` — пресеты: тени 8/14/24 м и стартовый internal scale 0.5/0.65/0.85. По умолчанию balanced.
- Frame governor опускает internal scale до 0.35 при перегрузе и возвращает вверх при запасе, с шагом 0.05 и выдержкой 1.5 с, чтобы разрешение не дёргалось. Наборы render targets кэшируются на предыдущий размер, поэтому возврат scale 0.75↔0.80 не переаллоцирует текстуры.
- Present mode по умолчанию `FifoRelaxed` (vsync без залипания на лишний vblank); `SHATTERBOX_NO_VSYNC=1` переключает на `Immediate` для замеров.
- Jitter TAA работает при любом scale, включая 100%: на native он даёт настоящее сглаживание, на меньшем internal — TAAU-апскейл. Jitter обнуляется только при выключенном TAA; при переключении TAA история сбрасывается.
- TAA: variance clipping по 3×3 (mean ± 1.35σ) вместо min/max и адаптивный blend 0.22…0.11 по стабильности пикселя.
- Gbuffer: MAX_STEPS 1024, primary ray 128 м, теневой луч до 24 м, AO до 16 м; детализация (`material_detail`, вариация блоков, тинт) больше не обрезается по расстоянию — вблизи и вдали одинаковая. Убрана тёмная обводка воксельных граней.
- GI: SSAO + SSGI + упрощённый VCT считаются одним half-res проходом `gi.wgsl`; irradiance-объём 32×8×32 (8 м ячейка) перестраивается `probe.wgsl` только при изменении мира/солнца/света, а не каждый кадр. Выключенные эффекты пропускают свой dispatch и пишут нейтральные значения.
- Volumetric fog: отдельный half-res проход `fog.wgsl` — height fog 14 шагов до 140 м, фаза Хени-Гринвуда по солнцу, видимость солнца из альфы irradiance-объёма (реальные тени от стен), аналитическое свечение точечных ламп. Композитится в `lighting.wgsl` до TAA. Стоит ~0.1 мс.
- На 2K (2560×1440) дефолтный governor (цель 144) сам выставляет scale 0.70 (1792×1008 internal) и держит ~150 fps на RTX 3050; native 1440p — 85.0 fps. Замеры ниже.
- `SHATTERBOX_QUALITY=performance` — первый выбор, если нужен максимум fps в тяжёлой сцене.
- Запускайте release-сборку для игры и замеров: `cargo run -p shatterbox-game --release`.

Переменные окружения:

- `SHATTERBOX_RENDER_SCALE=0.8` — фиксированный internal scale (0.35–1.0), governor выключается.
- `SHATTERBOX_FULLSCREEN=1` — запуск в borderless fullscreen.
- `SHATTERBOX_WIDTH` / `SHATTERBOX_HEIGHT` — размер окна (по умолчанию 1600×900).
- `SHATTERBOX_TIME=10.5` — стартовое время суток (0–24).
- `SHATTERBOX_SUN_TEMPERATURE=5800` — температура солнца в кельвинах (2000–12000).
- `SHATTERBOX_FOG=0.012` — плотность volumetric fog (0–0.15), `0` выключает дымку.
- `SHATTERBOX_QUALITY=performance` — пресет теней/разрешения.
- `SHATTERBOX_NO_VSYNC=1` — отключить вертикальную синхронизацию (для замеров).
- `SHATTERBOX_EXPOSURE=0.85` — экспозиция до tonemap (0.2–8.0).
- `SHATTERBOX_BENCHMARK=4` — прогон бенчмарка N секунд: печатает fps_mean/p50/p99, GPU и тайминги проходов, затем выходит.
- `SHATTERBOX_NO_HOT_RELOAD=1` — отключить hot reload шейдеров.
- `SHATTERBOX_EFFECTS=off|on|<mask>` — стартовый набор эффектов: битмаск 1 тени, 2 SSAO, 4 SSGI, 8 VCT, 16 TAA, 32 fog (например `SHATTERBOX_EFFECTS=63` — всё включено, `0` — всё выключено).
- `SHATTERBOX_SHADER_DIR=path` — альтернативная папка с `gbuffer.wgsl`, `lighting.wgsl`, `temporal.wgsl`, `bloom.wgsl`, `post.wgsl`, `gi.wgsl`, `probe.wgsl`, `fog.wgsl`.

Бенчмарк на 1440p (native internal scale, цель 110 fps):

```powershell
$env:SHATTERBOX_BENCHMARK="4"; $env:SHATTERBOX_WIDTH="2560"; $env:SHATTERBOX_HEIGHT="1440"
$env:SHATTERBOX_RENDER_SCALE="1.0"; $env:SHATTERBOX_NO_VSYNC="1"
.\target\release\shatterbox.exe 2>&1 | Select-String "BENCHMARK"
```

Результаты на RTX 3050 / DX12 / release (2560×1440 output):

| Режим | Internal | FPS mean | p50 | GPU | gbuffer |
|---|---|---|---|---|---|
| native (scale 1.0), все эффекты | 2560×1440 | 85.0 | 85.0 | 11.75 мс | 9.59 мс |
| native (scale 1.0), эффекты off | 2560×1440 | 101.6 | 101.6 | 9.78 мс | 8.12 мс |
| scale 0.9, все эффекты | 2304×1296 | 101.3 | 101.1 | 9.99 мс | 8.01 мс |
| governor (по умолчанию) | 1792×1008 (0.70) | 149.5 | 150.0 | 6.65 мс | 5.16 мс |

Volumetric fog в этих замерах включён; отдельный прогон `SHATTERBOX_EFFECTS=31` (без тумана) даёт 83–85 fps, то есть туман укладывается в шум. Снятие обрезания детализации по расстоянию тоже не стоило fps: стоимость определяет число лучей DDA, а не выборка материала.

Цена полного стека (RT-тени + SSAO + SSGI + VCT + TAA) в native — около 16 fps: 85.0 против 101.6 без эффектов. Из них основное — теневой луч в G-буфере (~1.3 мс), остальное — half-res GI (~1.2 мс). Поэтому по умолчанию включено всё, а оверлей позволяет выключить любое по отдельности.

Честно про 110 fps: в native 1440p primary DDA стоит ~8 мс даже при полностью выключенных тенях и AO, поэтому 110 fps на этом шейдере в native не берутся. Взять их можно на internal scale ≈0.9, либо отдельным half-res проходом видимости/теней (следующий шаг). Governor держит 150 fps на 0.70 — это и есть режим «144 стабильно» на 3050.

Hot reload включён по умолчанию: правь `crates/shatterbox-render/assets/shaders/*.wgsl`, изменения подхватываются примерно за 0.5–3 с. При ошибке компиляции остаётся предыдущий pipeline, ошибка пишется в лог.
