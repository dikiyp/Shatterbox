# voxel-world

Данные мира: воксели, кирпичи, регионы, палитра, LOD, детерминированные правки.

## Сначала прочитай

- `docs/ENGINE_PLAN.md`, разделы 5 (данные), 4.4 (регионы/LOD), 7.3 (пайплайн разрушения), 9 (бюджеты).
- `AGENTS.md` — инварианты и границы.

## Инварианты

- Воксель — `u16`: 10 бит материал + 6 бит вариант цвета (альтернатива 8+8). Не хранить на воксель структуру с albedo/roughness — только индекс в палитру.
- Палитра — массив записей: albedo, roughness, metalness, emissive, opacity, плотность, твёрдость, горючесть, звук. Материал 0 — воздух.
- Кирпич — 16×16×16 вокселей = 4096 × 2 B = 8 KB.
- Регион — 32×32×32 м. Brick-index региона — 16³ записей (кирпичи по 2 м) = 64 KB.
- Верхний уровень:
  - маленький уровень: 3D-текстура `R32_UINT` с индексом кирпича (0 = пусто);
  - открытый мир: 3D-текстура ID региона 32 м + пул дескрипторов (offset на brick-index и LOD), 0 = пусто.
- Маски занятости на кирпич: 16³ бит (512 B) + 8³ (64 B) + 4³ (8 B) + 2³ (1 B) = 585 B. DDA прыгает по маскам, а не по каждому вокселю.
- Правка: меняем воксели на CPU → dirty brick/region → заливка изменённого региона через staging ring в конце кадра. Никаких полных перестроек мира.
- LOD: LOD0 12.5 см (near-field, редактируемый), LOD1 25 см, LOD2 50 см, LOD3 1 м/impostor. Дальний LOD не разрушается в реальном времени.
- Детерминизм: целочисленные координаты, стабильные ID, фиксированный порядок обхода регионов/кирпичей, команда `{tick, seq, region, op, brush, material, seed}`.

## Адресация

Всегда проверяй границы и отрицательные координаты:

```text
world_voxel = floor(world_pos / voxel_size)
region      = floor_div(world_voxel, region_voxels)
local       = world_voxel - region * region_voxels
brick       = local / 16
in_brick    = local % 16
```

- Используй `div_euclid`/`rem_euclid` для отрицательных координат, не `/` и `%`.
- Умножения размеров — в `u64`/`usize` с проверкой, иначе 2048³ переполнит `u32`.
- Пустой регион/кирпич должен стоить O(1), а не обход 4096 вокселей.

## Типовые задачи

### Добавить get/set вокселя
1. Проверить границы мира.
2. Найти регион; если пуст — создать/выделить кирпич только при записи.
3. Найти кирпич и локальный индекс.
4. Записать `u16`; обновить маски 2³/4³/8³/16³; пометить dirty.
5. Вернуть старое значение для undo/сети.

### Палитра и материалы
- Не хардкодить материалы в шейдере; палитра — GPU-буфер, индексы стабильны.
- Вариант цвета — множитель/тинт, не отдельный материал.
- При добавлении материала не менять существующие индексы (сохранения/сеть).

### Сохранение региона
- Регион + LOD-уровни + delta-log правок; zstd; атомарная запись (temp + rename).
- Заголовок: версия, границы, палитра, таблица регионов, смещения.
- Порядок обхода детерминирован; иначе одинаковые миры дадут разные хеши.

### LOD
- Усреднение при понижении: доминирующий материал + средний цвет; не просто «первый воксель».
- Переходы — dithered + TAA; не менять LOD внутри кадра для одного региона.
- Near-field всегда LOD0; физика/GI — только near-field.

## Ловушки

- Смешениеworld-координат и индексов вокселей.
- Забыть обновить маску после правки → DDA «не видит» новый воксель.
- Кирпич на границе региона: локальные координаты не должны переполняться.
- `u16` материал >1023 при 10+6 — обрезается; проверять диапазон.
- Endianness/выравнивание при загрузке `.vxl`; явно `from_le_bytes`.
- LOD-швы и «дыры» на границах регионов; тестировать стыки.
- Полная перестройка brick map на каждую правку — запрещено.

## Тесты

- Адресация: отрицательные координаты, границы региона/кирпича, максимальный мир.
- Get/set: соседние воксели, masks after edit, dirty flags.
- Палитра: индексы стабильны, материал 0 = воздух.
- Сохранение/загрузка: round-trip, версия, повреждённый файл.
- Детерминизм: две одинаковые последовательности команд → одинаковый хеш.
- LOD: усреднение не теряет несущие материалы.

## Бюджеты

- Воксели ≤2.5 GB VRAM в открытом мире; квартал 250–500 MB.
- Правка без фризов >2 мс; заливка 8–16 MB/кадр.
- Не добавлять per-voxel аллокации и `Vec` в hot path.
