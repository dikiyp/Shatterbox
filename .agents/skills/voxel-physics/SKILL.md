# voxel-physics

Физика и разрушение: Jolt для тел, собственный DDA для игрока, гибридная коллизия мира.

## Сначала прочитай

- `docs/ENGINE_PLAN.md`, разделы 7 (физика/разрушение), 4.3 (детерминизм), 5.4 (динамические объекты), 9 (бюджеты).
- `AGENTS.md` — границы и производительность.

## Инварианты

- Jolt 5.6 через `oxijolt`; fallback Rapier. Игра работает только с трейтом `PhysicsBackend`.
- Игрок и лучи инструментов — **свой воксельный DDA/capsule sweep**, не Jolt. Мгновенно, точно, не зависит от пересборки коллайдеров.
- Обломки, транспорт, двери, ragdoll — тела Jolt.
- Столкновение с миром — статические коллайдеры секторов 8 м (64³ вокселей при 12.5 см), greedy box merge; создаются лениво вокруг активных тел.
- Сектор при правке → dirty → асинхронная пересборка за 1–2 кадра. Пока пересобирается, обломки могут кратко пройти сквозь свежую дыру — допустимо.
- Тело-тело — Jolt (convex hull/compound). Для больших кусков — compound из боксов, не миллион треугольников.
- Единицы — метры, килограммы, секунды; не смешивать с сантиметрами вокселей.

## Пайплайн разрушения

1. Shape query (сфера/капсула/бокс) по вокселям.
2. Удалить воксели, начислить импульс, заспавнить пыль/искры/дым.
3. Локальный flood fill 6-связности в грязном регионе.
4. Найти компоненты без якоря (земля/статика); отсоединить.
5. Скопировать компонент в динамический объект, удалить из мира.
6. Масса, центр масс, тензор инерции по вокселям/материалам.
7. Создать тело Jolt (hull/compound), выдать скорость.
8. Пометить кирпичи и GI-пробы dirty.

## Бюджеты

- ≤1.0–1.5 мс CPU на разрушение в кадре 144 fps.
- 50–100k вокселей/кадр на 144; до 200k на 60; остаток переносить.
- 100–200 активных тел рядом на 144; 300–500 на 60; дальше сон/слияние/запекание.
- Flood fill и пересборка секторов — в worker-пуле, не в главном потоке.
- При перегрузе резать обломки/частицы, потом физику, но не fps.

## Детерминизм

- Фиксированный шаг 60 Гц; стабильные ID; команды `{tick, seq, region, op, brush, material, seed}`.
- Jolt `cross-platform-deterministic` — не гарантия бит-в-бит сети; проверять на двух машинах.
- Порядок создания/удаления тел и обхода компонент фиксирован.
- Для коопа позже: сервер авторитетен, клиент предсказывает игрока, обломки — косметика/репликация.

## oxijolt-практика

- Держать FFI/unsafe в одном адаптере, с безопасной обёрткой.
- Не создавать/удалять тела в цикле по кадру без необходимости; пул тел.
- `MutableCompound` — для разрушаемых кусков; обновлять редко, не каждый кадр.
- Character controller — для NPC, но игрок может быть своим capsule sweep.
- Wheeled vehicle — Jolt; воксельный корпус — тело/compound.
- Проверять версию Jolt и glam; API обёртки может меняться.

## Ловушки

- Туннелирование быстрых обломков — substeps/CCD для мелких быстрых тел.
- Гигантский compound на весь дом → медленно; дробить на куски.
- Пересборка сектора каждый кадр → фризы; только dirty и асинхронно.
- Будить все тела при взрыве → CPU-взрыв; ограничить радиус/сон.
- Неверный центр масс → куски «висят» или крутятся странно.
- Смешение coordinate systems (Y-up vs Z-up) при импорте.
- Синхронизация физики и рендера: интерполяция, не чтение состояния в произвольный момент.

## Тесты

- Падающий куб на плоскость; стопка кубов стабильна.
- Взрыв пробивает стену; отсоединённые куски падают, сталкиваются, засыпают.
- Масса/центр масс/инерция для простых форм (куб, стена, балка).
- Сектор: правка → dirty → пересборка → обломок не проваливается.
- Детерминизм: одинаковые команды → одинаковое состояние тел (в допуске).
- Стресс: 200 тел, 60 Гц, без фризов >2 мс.
